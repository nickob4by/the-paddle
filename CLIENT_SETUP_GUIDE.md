# 🏓 White-Label Court Booking Template Guide

Welcome to the White-Label Court Booking & Management Platform template. Use this guide to spin up a completely customized instance for any new court, gym, or recreational club in under 5 minutes.

---


Antigravity will:
1. Run the database schema initialization on the new Turso DB.

3. Update brand identity, colors, and logos.
4. Prepare the Render deployment environment.

## 🛠️ Option B: Interactive CLI Wizard

You can run the interactive setup wizard at any time:

```bash
npm run setup:client
```

The wizard will interactively ask:
1. **Club / Facility Name**
2. **Brand Tagline & Contact details**
3. **Turso Database URL & Auth Token**
4. **Operating Hours (Opening & Closing times)**
5. **Admin Passcode / PIN**
6. **Courts count, Daytime hourly rate, Evening hourly rate, and Evening start hour**
7. **GCash Account Name, Mobile Number, and QR Code URL**

It will automatically:
- Connect to the new Turso database.
- Create all 7 tables with proper schemas & constraints.
- Insert facility settings and seed courts with multi-tier pricing.
- Generate `.env.local` and `client.config.json`.
- Output the exact Environment Variables to paste into Render.

## 📄 Option C: Headless Config File Mode

1. Duplicate `client.template.json` to `myclient.json`:
   ```bash
   cp client.template.json myclient.json
   ```
2. Fill in the client's information in `myclient.json`.
3. Run:
   ```bash
   npm run setup:client -- --config myclient.json
   ```

---

## 🗄️ Setting Up Turso Database (30 Seconds)

1. Go to [Turso Dashboard](https://turso.tech) (or use Turso CLI):
   ```bash
   turso db create <client-name>-court
   turso db show <client-name>-court --url
   turso db tokens create <client-name>-court
   ```
2. Copy the `libsql://...` URL and the token.

---

## 🌐 Deploying to Render (2 Minutes)

1. In [Render Dashboard](https://dashboard.render.com), click **New +** > **Web Service**.
2. Connect your GitHub repository.
3. Configure settings:
   - **Runtime**: `Node`
   - **Build Command**: `npm install; npm run build`
   - **Start Command**: `npm run start`
   - **Plan**: `Free` or `Starter`
4. Add the Environment Variables generated by the setup wizard:
   ```env
   TURSO_DATABASE_URL=libsql://...
   TURSO_AUTH_TOKEN=eyJ...
   NEXT_PUBLIC_BRAND_NAME=Smash Point Pickleball Club
   NEXT_PUBLIC_BRAND_TAGLINE=Premier Indoor Pickleball Hub
   NEXT_PUBLIC_CONTACT_PHONE=0917-xxx-xxxx
   NEXT_PUBLIC_DEFAULT_OPEN_TIME=06:00
   NEXT_PUBLIC_DEFAULT_CLOSE_TIME=23:00
   ```
5. Click **Create Web Service**. Your client's system is live! 🎉
